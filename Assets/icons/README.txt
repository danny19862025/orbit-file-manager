Orbit icon packs
================

These files are separate data files that Orbit reads at run time. They are not part of Orbit's own code
and keep their original licences (see the licenses folder):

  papirus.json   Papirus icon theme      https://github.com/PapirusDevelopmentTeam/papirus-icon-theme   GPL-3.0
  colloid.json   Colloid icon theme      https://github.com/vinceliuice/Colloid-icon-theme             GPL-3.0
  candy.json     candy-icons             https://github.com/EliverLara/candy-icons                     GPL-3.0
  adwaita.json   Adwaita icon theme      https://gitlab.gnome.org/GNOME/adwaita-icon-theme             LGPL-3.0 / CC BY-SA 3.0
  phosphor.json  Phosphor Icons          https://github.com/phosphor-icons/core                        MIT
  devicon.json   Devicon                 https://github.com/devicons/devicon                           MIT

Each pack holds a selection of the original folder and file-type SVGs (editor metadata removed), keyed by the
icon names Orbit uses. To rebuild one from a theme folder, or to use any other freedesktop.org icon theme,
choose Settings > Icons > Freedesktop theme.
